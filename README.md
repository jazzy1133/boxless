# Boxless

Your portal. No box. No hardware info.

## Download

Get the app from the [latest release](https://github.com/jazzy1133/boxless/releases/latest) — download `Boxless-0.4.1.apk`.

## Install

1. On your Android phone or TV, open the download in the browser and download the APK file.
2. Open the downloaded file.
3. When Android asks, allow the install — done.
