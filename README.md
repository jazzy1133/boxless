# Boxless
Your portal. No box. No hardware info.

## ⬇ [Download Boxless.apk](https://github.com/jazzy1133/boxless/raw/main/Boxless.apk)
Current version: 0.4.15 — tap the link, then open the downloaded file and allow install when Android asks. Future versions will also be offered as updates inside the app.

## What's new in 0.4.15

- **Search finally finds older titles** — searching Movies or Series now asks the portal itself, so a 2010 title like Victorious shows up in All instead of only the newest 840. Search inside a genre works too. Live channels are untouched.
- **Tablet layout uses the full screen** — in Movies/Series the empty right column collapses, so the poster grid spreads across the whole width (about 7–8 columns on the Tab A8 instead of 3). Channels still show the preview pane, and phones are unchanged.

## Install

1. Download `Boxless.apk` from this page.
2. Open the downloaded file.
3. When Android asks, allow the install — done.
